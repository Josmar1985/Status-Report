Compliance de Qualidade (BPx)

Farmacêutica: se o projeto impacta Boas Práticas (BPx), os itens abaixo (incluindo POP) são obrigatórios — Início/Fim/Real, cada um vira barra no Cronograma.

VSC — Validação de Sistemas Computadorizados

Só existe em projetos que mexem em sistema computadorizado. É uma validação do projeto como um todo — QI/QO/QD. Cada etapa aparece também como barra no Cronograma.
